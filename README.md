# Mundial

An interactive explorer for FIFA World Cup history (1930–2022): host stadiums
on a world map, a tournament timeline, and search across teams, players and
matches.

Built with Next.js, Leaflet, Recharts and Fuse.js. All data is static JSON in
`public/data/`, so there's no backend.

## Run locally

```bash
npm install
npm run dev
# -> http://localhost:3000
```

## Pages

- `/` — headline stats and entry points
- `/map` — host cities and stadiums by tournament
- `/timeline` — every World Cup, drilling into matches and goals
- `/search` — fuzzy search over teams, players and matches

## Data

`public/data/*.json` is generated by `scripts/process-data.mjs` from the
[Fjelstul World Cup Database](https://github.com/jfjelstul/worldcup) CSVs,
which it reads from `data/raw/` (git-ignored). Stadium coordinates come from
`scripts/city-coords.mjs`.

```bash
node scripts/process-data.mjs
```
